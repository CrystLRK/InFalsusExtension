# 独占全屏

游戏原版显示设置中的全屏模式扩展为：

1. `Windowed`：窗口模式；
2. `FullScreenWindow`：原版无边框全屏；
3. `FullScreen`：真正的独占全屏。

选择第三项后，Mod 使用游戏当前选择的解析度和刷新率请求
`ExclusiveFullScreen`。独占模式通常会隐藏网易云桌面歌词和其他
非注入式桌面叠加层。

## 配置

模式同时保存在 Melon Preferences：

```text
UserData/MelonPreferences.cfg
```

配置项：

```ini
[InFalsusChartExt]
DisplayMode = "ExclusiveFullScreen"
```

允许的值：

- `FollowNative`：不主动覆盖原版模式；
- `Windowed`；
- `FullScreenWindow`；
- `ExclusiveFullScreen`。

通过游戏显示设置选择模式后会自动写入配置。修改配置文件后需要重启游戏。

## Alt+Tab

如果当前模式为 `ExclusiveFullScreen`，应用重新获得焦点后会按游戏当前
分辨率与刷新率重新进入独占全屏。

## 失败回退

如果显示器或图形驱动未能进入独占全屏：

- 自动回退到原版 `FullScreenWindow`；
- 将配置改回 `FullScreenWindow`；
- 在游戏画面上方显示短暂警告。

该回退只执行一次，不会反复切换显示模式。
